# Features — prioritised

Every feature has an ID so the plan, commits and README can refer to it.

**Tiers**
- **P0 — Must.** Explicitly required by the brief. Without these the submission is incomplete.
- **P1 — Should.** Edge cases the brief hints at but doesn't spell out. These are what the "feature intuition" (30%) and "stakeholder understanding" (30%) scores reward. They're cheap if designed in from the start.
- **P2 — Nice.** Polish and extras. Only do them once P0 and P1 are done.

Rubric key: **S** = stakeholder understanding, **F** = feature intuition, **T** = technical quality, **A** = AI usage.
